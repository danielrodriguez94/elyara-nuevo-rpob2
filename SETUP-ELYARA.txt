1. SUPABASE
-----------
Create a new Supabase project for ELYARA.

A) SQL
Open SQL Editor and run the full contents of supabase.sql.

B) Google provider
Authentication -> Providers -> Google -> Enable.
Use your Google Cloud OAuth Client ID and Client Secret.

C) URL configuration
Authentication -> URL Configuration:
- Site URL: your final ELYARA domain.
- Add redirect URLs for:
  https://YOUR-DOMAIN/login.html
  https://YOUR-PAGES-PROJECT.pages.dev/login.html

D) Front-end keys
Project Settings -> API:
Copy:
- Project URL
- anon/public key

Paste them into config.js:
SUPABASE_URL
SUPABASE_ANON_KEY

The anon key is intended for browser use with RLS.
Never place the service_role key in config.js.

2. CLOUDFLARE PAGES SECRETS
---------------------------
Workers & Pages -> your ELYARA project -> Settings -> Variables and Secrets.

Add:

STRIPE_SECRET_KEY
  Your Stripe secret key. Encrypt it.

STRIPE_WEBHOOK_SECRET
  Stripe webhook signing secret. Encrypt it.

SUPABASE_URL
  Your Supabase project URL.

SUPABASE_ANON_KEY
  Your Supabase anon/public key.

SUPABASE_SERVICE_ROLE_KEY
  Your Supabase service_role key. Encrypt it.

Redeploy after saving them.

3. STRIPE

The website creates Stripe Checkout Sessions on the server through:
  /api/create-checkout

Direct-deposit services currently enabled:

- Business Website — starting scope $650 -> 50% deposit $325
- Digital Business Card — from $25 -> deposit from $12.50
- Social Media Flyer — from $25 -> deposit from $12.50
- Digital Menu 1 page — from $35 -> deposit from $17.50
- Digital Menu 2–3 pages — from $50 -> deposit from $25
- Elaborate Digital Menu — from $65 -> deposit from $32.50

Professional Website, Advanced Website and maintenance plans go to quote first.

Stripe webhook:
Create an endpoint in Stripe:
  https://YOUR-DOMAIN/api/stripe-webhook

Listen for:
  checkout.session.completed

Copy its signing secret into STRIPE_WEBHOOK_SECRET in Cloudflare.

4. GOOGLE CLOUD
---------------
Create or reuse a Google OAuth 2.0 Web Client.

Authorized redirect URI must include the callback shown in:
Supabase -> Authentication -> Providers -> Google.

The browser starts Google login through Supabase, not directly through a secret in the website.

Use Stripe test mode first.

Then switch STRIPE_SECRET_KEY and webhook to live-mode credentials.

SECURITY
--------
Never commit:
- Stripe secret key
- Stripe webhook secret
- Supabase service_role key
- Google client secret

They belong only in Cloudflare/Supabase/Google secure settings.
